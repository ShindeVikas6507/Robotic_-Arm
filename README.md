# 🤖 Robotic Arm CAD Model

This repository contains the CAD models and design files of a robotic arm.

## 📌 Project Overview

This project focuses on the design and development of a robotic arm consisting of multiple mechanical components. Each component is organized separately to make the CAD files easy to understand, access, and use.

## 🔩 Robotic Arm Components

The robotic arm consists of the following parts:

* Base
* Lower Base
* Upper Base
* Link 1
* Link 2
* Gripper

## 📂 Repository Structure

```text
CAD/
├── Base/
├── Lower_Base/
├── Upper_Base/
├── Link_1/
├── Link_2/
└── Gripper/

Assembly/
└── Robotic_Arm_Assembly/
```

## 🛠️ CAD Files

Each component folder contains the corresponding CAD files and, where available, STL files for manufacturing or 3D printing.

## 🔧 Assembly

The complete robotic arm assembly is provided in the `Assembly` folder.
